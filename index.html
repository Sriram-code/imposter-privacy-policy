Privacy Policy — Imposter

Last updated: September 25, 2026

Contact: sm0058735@gmail.com

Imposter is a multiplayer party game designed to be played by a group of people in the same room. The app does not require an account, email address, phone number, or sign-in.

1. Summary

We do not collect, sell, or use personal information for advertising or tracking.

Imposter does not contain advertising SDKs, analytics SDKs, or social media integrations.

The game primarily operates between players' devices over the same local Wi-Fi network or mobile hotspot.

2. Information Stored on Your Device

Imposter stores a limited amount of information locally on your device to allow games to function correctly and support reconnection to an ongoing game.

Information Purpose
Random device identifier Distinguishes your device during a game
Random player identifier Allows you to reconnect as the same player
Session token Helps authenticate reconnection to the current game
Display name Identifies you to other players in the game
Current room code and game state Allows an interrupted game to be resumed
App settings Stores preferences such as sound and vibration settings

These identifiers are randomly generated by the app. They are not advertising identifiers and are not linked to your Google account.

The information listed above is stored locally on your device and is not used to identify you personally.

Secret words and player roles are not intentionally persisted to permanent local storage.

3. Information Shared on the Local Network

During a local multiplayer game, devices communicate directly over the same Wi-Fi network or mobile hotspot.

Information shared between players may include:

  • Display names
  • Player connection status
  • Ready status
  • Public game state
  • Investigation/check results
  • Votes
  • Eliminations
  • Other information required to synchronize the game

This information is used only to operate the current game. The app does not upload local gameplay information to a central gameplay server.

4. Information Sent Over the Internet

When a new game is started, the host device may make a request to our word-generation service to generate a pair of related words.

The request may contain:

  • Selected difficulty
  • Selected word category
  • Number of players
  • Number of impostors
  • A randomly generated request identifier

The app does not intentionally send:

  • Player names
  • Player roles
  • Secret words from the game
  • Votes
  • Investigation history
  • Device identifiers
  • Location information
  • Contacts
  • Photos or media

5. Word Generation Service

The word-generation service is hosted using a third-party cloud hosting provider and runs the Qwen3-based word-generation system used by Imposter.

The service is not used to create user accounts, track players, or build user profiles.

Server and infrastructure providers may maintain temporary technical logs as part of normal service operation, security, and reliability.

6. Offline Word Bank

If Use Offline Word Bank is enabled, Imposter uses word pairs included within the application and does not need to contact the word-generation service.

7. Permissions

Permission / Capability Purpose
Internet Generate word pairs using the word-generation service
Network access / network state Detect network availability and support multiplayer communication
Wi-Fi / local network access Communicate with nearby players
Network discovery Discover nearby game hosts where required
Vibration Optional haptic feedback

The app does not intentionally request access to:

  • Location
  • Contacts
  • SMS or messages
  • Camera
  • Microphone
  • Photos
  • Personal files

8. Children

Imposter does not require users to create an account and does not intentionally collect personal information from users.

The app does not contain advertising or social-media functionality.

9. Third-Party Services

Imposter does not contain advertising networks, analytics services, or social-media integrations.

The app uses a third-party cloud hosting service to operate the word-generation API. The API receives only the limited game-generation parameters described above.

10. Your Choices

  • Enable Use Offline Word Bank to avoid requests to the word-generation service.
  • Leave an active game to remove its stored game state according to the app's local storage behavior.
  • Clear the app's data through Android Settings to remove locally stored information.
  • Uninstall the app to remove locally stored information.

11. Data Security

The app is designed to minimize the amount of information transmitted outside the local multiplayer network.

Local multiplayer data is exchanged between participating devices on the local network. Internet communication with the word-generation service is used only when required to generate a new word pair.

12. Changes to This Privacy Policy

We may update this Privacy Policy when the app's functionality or data practices change. When changes are made, the updated policy will be published at this URL and the Last Updated date will be changed accordingly.
